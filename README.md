# Pixel Arcade

A dark game-library website inspired by retro game hubs.

## Features

- Searchable game library
- Category filtering
- Responsive layout
- Snake
- Memory Match
- Reaction Rush
- Tic-Tac-Toe
- Number Guess
- Coin Flip
- Works with GitHub Pages
- No backend required

## Run locally

Open `index.html` in a browser.

## Publish on GitHub Pages

```bash
git init
git add .
git commit -m "Create Pixel Arcade game hub"
git branch -M main
git remote add origin https://github.com/YOUR\_USERNAME/YOUR\_REPOSITORY.git
git push -u origin main
